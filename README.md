# モニタリングノート

GitHub Pages 用です。`index.html` / `style.css` / `app.js` / `bg.jpg` / `README.md` を同じ階層にアップロードしてください。

## 今回の追加
- 利用者一覧を50音順（ふりがな優先）で表示
- 名前の横に次回モニタリング月を控えめに表示
- 利用者詳細に誕生日を表示
- 利用者詳細で入院日・退院日を記録し、入退院履歴を保存
- 入院中の利用者をホームの「入院中」欄に分離
- 退院後は対象者カードに退院日を小さく表示
- モニタリングごとに実施者を保存。入力済みの実施者は次回候補として再利用
- 履歴・テキスト出力にも実施者名を表示

データはブラウザの localStorage に保存されます。
