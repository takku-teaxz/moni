# モニタリングノート
GitHub Pages向けの静的Webアプリです。`index.html` / `style.css` / `app.js` を同じ階層に置いて公開してください。

## 今回の仕様
- 利用開始日の翌月を「初回モニタリング」対象月として自動設定
- その後は誕生月を基準に3か月おき（誕生月・+3・+6・+9月）の対象月を自動設定
- 例：9月利用開始・8月誕生 → 初回10月 → 定期11月 → 2月 → 5月 → 8月…
- 利用者に「相談事業所」「相談員名」を登録し、カードからすぐ確認可能
- モニタリング入力時に前回記録を項目別に比較可能
- 履歴は月別の対象者・完了率を表示

データはブラウザの localStorage に保存されます。同じURLでも別端末・別ブラウザには自動同期されません。
