# モニタリングノート

GitHub Pages 用です。`index.html` / `style.css` / `app.js` / `bg.jpg` / `README.md` を同じ階層にアップロードしてください。

## 今回の追加
- 利用者一覧を50音順（ふりがな優先）で表示
- 名前の横に次回モニタリング月を控えめに表示
- 利用者詳細に誕生日を表示
- 利用者詳細で入院日・退院日を記録し、入退院履歴を保存
- 入院中の利用者をホームの「入院中」欄に分離
- 退院後は対象者カードに退院日を小さく表示
- モニタリングごとに実施者を保存。入力済みの実施者は次回候補として再利用
- 履歴・テキスト出力にも実施者名を表示

データはブラウザの localStorage に保存されます。


## 今回の調整
- 円グラフ（進捗リング）を金色1色に統一
- 退院歴のある今月対象者を一覧の上に優先表示
- 入院中の利用者はホーム最下部へ移動（記録対象と分離）
- 利用者詳細の入退院入力欄がスマホ幅からはみ出さないよう修正


## カレンダー更新
- モニタリング完了日に加え、利用者詳細で登録した入院日・退院日を履歴カレンダーへ自動表示します。
- 入退院は既存データを利用するため二重入力は不要です。


## ホーム画面アイコン
猫の「モニ」アイコンを組み込み済みです。GitHub Pagesへこのフォルダ内のファイルをすべてアップロードしてください。iPhoneではSafariでページを開き、「共有」→「ホーム画面に追加」でアイコンが表示されます。すでにホーム画面へ追加済みの場合は、一度削除して追加し直すと新しいアイコンが反映されやすいです。
